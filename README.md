# BluFeather Resume Classifier

Welcome to the **BluFeather Resume Classifier** repository! This project leverages Python to classify resumes efficiently. With its integration into Hugging Face Spaces, it provides an intuitive interface for users to interact with the model.

## 🌟 Features

- **AI-Powered Resume Matching Model**: Developed and trained using DistilBERT, incorporating PDF text extraction and achieving a 30% improvement in match accuracy over traditional keyword-based systems.
- **Interactive Web Interface**: Deployed a production-grade FastAPI backend with a user-friendly interface, enabling seamless resume uploads, dynamic job description inputs, and real-time match score prediction through Hugging Face Spaces.
- **Containerized Application**: Ensures clean, reproducible builds and compatibility with Hugging Face’s deployment infrastructure using Docker.

## 🚀 Usage

To get started, visit the project on Hugging Face Spaces: [BluFeather Resume Classifier](https://huggingface.co/spaces/Yashraj-146/resume-classifier).
